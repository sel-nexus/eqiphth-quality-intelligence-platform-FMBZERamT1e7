# EQIP Quality Platform

Existing Vite/React demonstration portal. Its login screen supports persona selection and a locally stored demo session; it is not a production authentication service.

## Local development

Install dependencies with `npm install`, then run `npm run dev`. Build with `npm run build`. Run component tests with `npm test`. To run browser tests, install Chromium with `npx playwright install chromium` and run `npx playwright test`.

The login footer uses a fixed 2026-27 range. The copyright owner and final wording require owner approval before release.
